## Notable Divergence

None. The Lean model `varint_len_nat` is an exact transcription of the Rust
`varint_len` function — same thresholds, same return values. The test confirms
there is no divergence.

The one deliberate difference: for `v > MAX_VAR_INT`, the Rust function
panics (`unreachable!()`), while the Lean model returns 0 (modelling the
invalid branch as a distinguished out-of-range value). This case is excluded
from the test domain.
